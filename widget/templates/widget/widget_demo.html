DÉMO — page tierce

Votre site, avec un bouton « Transcrire »

Cette page simule un site tiers. Le bouton flottant en bas à droite est le widget Qwen3-ASR : cliquez pour enregistrer votre voix ou déposez un fichier audio.

Comment l'intégrer chez vous ?

Deux lignes de code, n'importe où dans votre <body> :

<script>
  window.QWEN3ASR_WIDGET = {
    apiBase: "{{ request.scheme }}://{{ request.get_host }}",
    position: "bottom-right",
    accent: "#3a6fd8",
    title: "Transcription vocale"
  };
</script>
<script src="{{ request.scheme }}://{{ request.get_host }}{% static 'widget/qwen3asr-widget.js' %}"></script>

Le script crée automatiquement le bouton flottant, sans conflit avec votre CSS ni votre JavaScript (tout est encapsulé, préfixe qw3-).

Options disponibles

{
  apiBase:    "https://votre-serveur-asr",  // requis si script hébergé ailleurs
  position:   "bottom-right",               // bottom-left | top-right | top-left
  accent:     "#3a6fd8",                    // couleur principale
  title:      "Transcription vocale",       // titre du panneau
  lang:       "",                           // force la langue ("fr", "en"…)
  timestamps: false,                        // true = segments avec timestamps
  maxTokens:  512,                          // limite de tokens générés
  history:    true,                         // false pour masquer l'historique
  historyMax: 30,                           // nombre d'entrées conservées
  download:   true,                         // false pour masquer le téléchargement
  format:     "txt"                         // "txt" ou "json" — format d'export
}
